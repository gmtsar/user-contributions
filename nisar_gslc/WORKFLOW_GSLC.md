# Workflow and Parameters

**English** | [简体中文](WORKFLOW_GSLC.zh-CN.md) · [Home](README.md)

Run the commands below from the `nisar_gslc/` package directory.

## 1. Prepare the project

Place exactly two GSLC acquisitions containing A/B in `raw/`, then run:

```bash
./run1_prepare_GSLC_LA_LB.csh
```

Preparation reads acquisition times, frequency metadata, projection and pixel
spacing; checks the pair; creates LA/LB, configurations and `gslc_project.json`.
Input HDF5 files remain read-only. The default extent is the full common map
grid; product masks determine actual valid coverage within it.

For a diagnostic subset, use `--bbox XMIN XMAX YMIN YMAX` on preparation,
with coordinates in product-CRS metres. Use a new project to change the pair or
extent. Pair names use UTC acquisition dates and standard day-of-year (January
1 = 001), which may differ from older zero-based GMTSAR directory conventions.

## 2. Edit configurations

The active files after preparation are:

```text
LA/config_GSLC_A.txt
LB/config_GSLC_B.txt
config_IONO.txt
```

Use `key = value`; `#` introduces a comment. Templates in `configs/` are copied
only for a new project. Editing templates does not change an existing project's
active settings.

| Setting | A default | B default | Meaning |
| --- | --- | --- | --- |
| `filter_wavelength` | 120 | 480 | Interferometric Gaussian wavelength, metres |
| `output_spacing_x` | 40 | 120 | Easting grid spacing, metres |
| `output_spacing_y` | 40 | 120 | Northing grid spacing, metres |
| `goldstein_mode` | coherence | coherence | Exponent adapts to patch coherence |
| `filter_patch` | 32 | 32 | Goldstein patch side length, output pixels |
| `correlation_threshold` | 0.1 | 0.1 | Quality threshold for unwrapping |
| `unwrap_mode` | smooth | smooth | SNAPHU cost mode |
| `effective_looks` | 32 | 8 | Provisional SNAPHU statistical parameter |
| `unwrap_tiles_y/x` | 4 / 4 | 2 / 2 | Full-scene tile layout, north/east |
| `unwrap_overlap_y/x` | 512 / 512 | 512 / 512 | Overlap in output pixels |
| `unwrap_nproc` | 2 | 2 | Simultaneous tiles within one band |
| `min_valid_fraction` | 0.8 | 0.8 | Minimum valid block/Gaussian support |

Output spacings must be integer multiples of the respective native spacings
read from HDF5. The software does not invent a finer B resolution. Gaussian
wavelength is independent of grid spacing; its standard deviation follows
GMTSAR's `sigma = wavelength / 5.3`, with approximately ±2 sigma support.

For a fixed Goldstein exponent, set `goldstein_mode = fixed` and
`filter_alpha = 0.5`. Keep `filter_alpha` commented in coherence mode.
`filter_patch` must be a power of two, at least 8. A small diagnostic subset
may need `unwrap_tiles_y = 1` and `unwrap_tiles_x = 1` in both band settings.
A/B run sequentially; `unwrap_nproc` controls parallel tiles within each band.

The independent ionospheric configuration is:

```text
filter_wavelength = 20000
prefilter_a = 1000
coherence_threshold = 0.1
coarse_samples_per_wavelength = 8
surface_tension = 0.1
interpolate_phase = 0
nearest_grid_radius = 300
```

Here `filter_wavelength` and `prefilter_a` are in metres. They are separate
from A/B interferometric filtering. `interpolate_phase = 1` enables optional
solver-only nearest-neighbor phase filling in run4/run6; its radius is in
output pixels. Scientific results restore the original valid/coherence mask.
The default is 0, with no solver-only filling.

## 3. Interferometry and unwrapping

Run2 matches the two scenes by their actual map-coordinate pixel centers and
checks CRS, spacing and grid compatibility. It reads native valid masks and
uses only jointly valid complex samples. The phase convention is:

```text
I = reference * conjugate(secondary)
P1 = abs(reference)**2
P2 = abs(secondary)**2
phase = angle(weighted_mean(I))
coherence = abs(weighted_mean(I)) / sqrt(weighted_mean(P1) * weighted_mean(P2))
```

Gaussian weights are normalized over valid support before decimated output
sampling. Correlation then receives a GMTSAR-style 3×3 weighting while masked
holes stay masked. `phase.grd` is the Gaussian-weighted wrapped phase;
`corr.grd` is coherence. Goldstein calls the existing `phasefilt` program and
writes `phasefilt.grd`. In adaptive mode its exponent is
`1 - patch_weighted_coherence`. The former test-only `phase_raw.grd` is not
produced by the staged workflow.

Run3 previews the quality mask. Run4 reads the existing filtered phase and
coherence, runs SNAPHU, restores accepted valid pixels, and writes
`unwrap.grd`, `conncomp.grd` and `los.grd`. No landmask is generated by default.
An optional `landmask.grd` in a band result directory must have exactly the
same grid; values greater than 0 are retained.

Run4 reuses intact, current `display_amp.pdf`, `phase.pdf`, `corr.pdf` and
`phasefilt.pdf` plus their CPTs. It draws `unwrap.pdf` and `los.pdf` and rebuilds
the complete bundle. Missing/stale figures are redrawn. `plots.json` records
`reused_pdfs` and `generated_pdfs`. Explicit redraw:

```bash
python plot_gslc_gmt.py LA/intf/<pair> --overwrite
```

Replace `<pair>` with the actual pair directory.

## 4. Estimate ionosphere and re-unwrap A

Run5 linearly interpolates A unwrapped phase to B's actual map coordinates,
uses nearest-neighbor sampling for A coherence, and optionally prefilters A
on B. Frequencies come from HDF5 metadata recorded in the band reports.
For `fB > fA`, the A-frequency ionospheric estimate before spatial filtering is:

```text
r = fA / fB
iono_A = (phase_A_on_B - r * phase_B) / (1 - r*r)
```

Mean A/B coherence and a frequency-dependent outlier interval select reliable
samples. Nearest filling, median → boxcar → median → boxcar → Gaussian → GMT
surface reconstruction follow the upstream method. The filtered field returns
to A's original coordinates and valid footprint. Edge extrapolation is limited
to 1.5 B pixel spacings; unsupported areas remain NaN.

Run5 writes `iono_correction_filt.grd`, `unwrap_corrected.grd`, the corrected
wrapped `phase_LA_after.grd`, and corresponding LOS products. Run6 supplies
that corrected wrapped phase to SNAPHU, without another Gaussian/Goldstein
pass, then writes the final A unwrap and LOS.

## 5. Optional polygon mask: preview first

Ordinary run5 does not apply an additional polygon. To exclude a detached
region, use the masked branch after run4. Vertices are ordered around the
polygon, in product-CRS metres. `exclude` removes its interior; `keep` retains
its interior. These example coordinates belong to the development T112A scene;
choose new coordinates for another footprint.

```bash
./run5mask_iono_GSLC_LA_LB.csh 1 --mask-mode exclude \
  --mask-polygon 505000 3505000 750000 3575000 \
                 765000 3525000 520000 3455000
```

Inspect `iono_correction_mask/preview/LA/mask_preview.pdf` and the LB preview.
Mode 1 saves the selection; it does not estimate ionosphere. After review:

```bash
./run5mask_iono_GSLC_LA_LB.csh 2
./run6_corrected_GSLC_LA.csh \
  --iono-dir iono_correction_mask -o LA_iono_corrected_mask
```

Mode 2 uses the saved selection. Results are in `iono_correction_mask/result/`
and geographic outputs in `result/lonlat/`. Changed selections require a new
mode 1 preview. Previous results move to `history/`; a lock prevents concurrent
masked runs in the same directory. Run6 validates the saved result and carries
the mask into corrected phase, coherence, unwrap and LOS.

Equivalent Python calls are:

```bash
python gslc_workflow.py mask 1 --mask-mode exclude \
  --mask-polygon 505000 3505000 750000 3575000 \
                 765000 3525000 520000 3455000
# Inspect the preview before continuing.
python gslc_workflow.py mask 2
python gslc_workflow.py correct \
  --iono-dir iono_correction_mask -o LA_iono_corrected_mask
```

## 6. Coordinates, LOS and export controls

GSLC is already geocoded. Run4–run6 export geographic products by reprojection,
using nearest-neighbor resampling, not the RSLC `trans.dat` geocoding route.
Native CRS metadata is retained. Geographic grids use EPSG:4326 with axes in
degrees. Internal rasterio reprojection and netCDF4 writing avoid dependence
on external `gdalwarp` HDF5/netCDF plugins.

LOS uses each band's wavelength: `-wavelength/(4*pi) * unwrap`. Grid units are
metres; plots show millimetres, positive toward the satellite. No reference
area or constant subtraction is applied by default; phase datum ambiguities
remain. All maps are unshaded and colorbars are below the map.

Individual stages support `--no-pdf`; run4–run6 still export geographic grids.
They also support `--no-lonlat`. The all-stage controller supports `--no-pdf`.
For a separate geographic export or optional GeoTIFF:

```bash
python reproject_gslc.py LA/intf/<pair> --resume --pdf
python reproject_gslc.py LA/intf/<pair> --resume --geotiff
```
